# DOM, events och formulärhantering

Denna laboration handlade om att lära sig implementera de kunskaper vi fått om JavaScript på en webbplats. Utöver grunderna har vi under denna period även lärt oss en del om DOM-manipultion, eventlyssnare och hur man kan spara data på webbplatser. Det sistnämnda har i denna labb skett genom localstorage.

## Reflektioner kring arbetet

Denna laboration var helt klart den svåraste hittills. Det är dock ganska roligt att man kan tycka att någonting är så svårt att förstå ena veckan för att sedan kännas enkelt i förhållande till nya utmaningar veckan efter. Ungefär så har jag känt inför grunderna i JavaScript nu när vi började med denna labb - grunderna var faktiskt inte så farliga.

Något jag tar med mig från denna labb är hur viktigt det är att kommentera koden löpande när dokumenten blir så stora. Även hur viktigt det är att faktiskt kommentera på ett sätt så att man förstår i efterhand! Jag kommenterade väldigt lite själv under projektets gång utan försökte förhålla mig till de kommentarer som fanns i den givna filen. Jag insåg dock när jag fick lite problem i slutfasen av labben att kommentarerna som fanns inte hjälpte mig att förstå koden i många fall.

Jag känner att jag behöver öva väldigt mycket mer på detta område och ser fram emot att befästa dessa kunskaper i kommande kurser. Det är svårt att komma ihåg alla steg när det kommer till DOM-manipulation och det känns som att vägen till framgång helt enkelt är att nöta det så mycket som möjligt. Även localstorage var rätt klurigt, men som med allt annat så kändes det relativt logiskt när man väl förstod vad det gör och vad man kan använda det till.
